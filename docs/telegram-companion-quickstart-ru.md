# Быстрый запуск Telegram на Debian

Один раз настраиваешь ноутбук — пользователи плагина подключаются к общему
боту по личной ссылке. Им не нужны собственные серверы или ключи бота.

BotFather регистрирует бота. Наша служба на ноутбуке обрабатывает сообщения.
Obsidian передаёт выбранные материалы и забирает результаты. Новые карточки
и перенос результатов требуют работающего Obsidian.

## 1. Получи ключ бота

В Telegram открой [официального BotFather](https://t.me/BotFather), отправь
`/newbot` и выбери название и username. Он выдаст token — ключ доступа к боту.
Сохрани его и вводи только в установщике; в чат присылать его не нужно.
Если бот уже создан, можно использовать существующий ключ.
[Инструкция Telegram](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).

## 2. Подготовь ноутбук

Нужны Debian 12 или новее, x86-64 либо ARM64, systemd и интернет.
Порты TCP **80 и 443** на роутере должны вести на ноутбук; 8787 открывать не нужно.
Оставь ноутбук включённым и проверь настройки сна при простое и закрытии крышки.

Скопируй серверный ZIP на ноутбук и распакуй **целиком в отдельную папку**.
Открой терминал в этой папке. Если `python3 --version` отсутствует:

```sh
sudo apt update
sudo apt install python3
```

## 3. Запусти установщик

```sh
sudo python3 install.py
```

Укажи публичный IP и введи ключ бота. Символы ключа при вводе не показываются.
Проверь показанный план и введи `INSTALL`, чтобы подтвердить установку.

Установщик подготовит программы, закрытую конфигурацию, HTTPS, продление
сертификата и автозапуск. Системный Node.js и чужие сайты он не заменяет.
При конфликте с существующей установкой он остановится с объяснением.

Сертификат для IP выдаёт Let's Encrypt; условия показываются до установки.
Для проверки адреса порт 80 должен быть доступен из интернета.
[Об IP-сертификатах](https://letsencrypt.org/2026/03/11/shorter-certs-certbot).

Сохрани выданный адрес `https://ТВОЙ_IP`. Если старый сервер обслуживает этого
же бота, останови старую службу. Установщик сам не удаляет старый webhook.

### Если порты уже обслуживает другой прокси

Для существующего nginx или Caddy есть режим установки **только службы бота**:

```sh
sudo python3 install.py --existing-proxy --bind-address 172.18.0.1
```

Здесь `172.18.0.1` — пример адреса Docker-моста на хосте; используй проверенный
адрес, доступный твоему прокси. Этот режим принимает только частный IPv4
из диапазонов 10/8, 172.16/12 или 192.168/16. Адрес обязателен: установщик
проверит возможность привязки к нему и доступность порта 8787.
Он не настраивает чужой прокси, HTTPS или сертификаты и не запускает nginx.
Перед подключением Obsidian настрой и проверь HTTPS через действующий прокси
по разделу «Existing reverse proxy» в `INSTALL.md`. Порт 8787 не пробрасывай.

## 4. Подключи Obsidian

1. Открой **Anchor Recall → Интеграции → Telegram**.
2. Введи HTTPS-адрес и нажми **«Подключить Telegram»**.
3. Открой одноразовую ссылку, нажми **«Начать»** в Telegram и вернись в плагин.
4. Выбери материалы, разреши их передачу и заверши подключение.

Открой Mini App кнопкой меню бота или командой `/app` (`/go` открывает тот же экран).
В нём проходят занятия: свободный ответ, один или несколько вариантов, пропуски,
сопоставление и порядок. Проверка использует те же правила, что Obsidian.
После ответа выбери оценку вспоминания; совпадение текста само по себе расписание
не меняет. В чате остаются уведомления, подключение, статус и отключение.
Подробности настройки меню и работы — в `MINIAPP-ru.md` рядом с установщиком.

Чтобы повторять при закрытом Obsidian, включи **«Повторять FSRS-карточки, когда
Obsidian закрыт»**, подтверди передачу и нажми **«Синхронизировать сейчас»**.
Копируются активные FSRS Core-карточки выбранных материалов, включая будущие
сроки, состояния и параметры FSRS. Новая копия не имеет общей квоты карточек и
материалов и после подтверждения нового срока действует до 30 дней. Для этого
обнови плагин и сервер, подтверди передачу и синхронизируй копию. Копия передаётся порциями,
повторно отправляются только изменившиеся части. Вложения требуют
своего отдельного разрешения. Бот рассчитывает следующие сроки сам, показывает
время ближайшего короткого повтора и кнопку **«Продолжить»**. Сервер и его интернет
должны работать. При возвращении Obsidian ответы применяются по порядку и ровно
один раз, с исходным временем и отдельными событиями истории. Конфликтующие
локальные изменения сохраняют приоритет; отказ виден в статусе.

В меню бот показывает сохранённые названия материалов из Obsidian. В сообщениях
с вопросом и ответом заголовок материала не повторяется. Подсказки приходят по одной, каждое сообщение
со своим спойлером; следующую запрашиваешь кнопкой «Следующая подсказка».

Фоновая синхронизация сохраняет кнопки текущего вопроса, если сама карточка
не изменилась. Изменённый вопрос нужно открыть заново через `/go`.

Перед вложением появится «Загружаем изображение…» (или аудио/видео), затем
это же сообщение превратится в файл. При ошибке бот покажет предупреждение;
повторную попытку можно начать через `/go`. Оценка ждёт подтверждения загрузки.

В шаге выбора материалов можно отдельно разрешить подсказки и вложения:
изображения, аудио и видео до 50 МБ на файл. После изменения этого разрешения
снова подтверди передачу, сохрани выбор и нажми «Синхронизировать сейчас».
Существующие подключения сами это разрешение не получают. Фрагмент записи
сначала сохрани отдельным файлом: исходная запись целиком не отправляется.
Файлы встраиваются в сообщения или приходят документами в зависимости от
формата. Локальные пути и остальные материалы не передаются; Банк остаётся
отдельным. Расписание Core обновляется при синхронизации результата с Obsidian.

Если оба компьютера за одним роутером, публичный HTTPS-адрес должен открываться
и из локальной сети. При отсутствии NAT loopback понадобится настройка роутера.

## Обновить уже работающий сервер

Скопируй новый полный серверный архив на ноутбук и распакуй в отдельную папку.
Не запускай установщик заново. Из новой папки:

```sh
sudo python3 update.py --check
sudo python3 update.py
```

Первый вызов проверяет пакет и конфигурацию офлайн. Второй останавливает только
службу бота, сохраняет закрытую копию всей конфигурации и журналов, заменяет
программу и проверяет локальный мост. Caddy, Docker, VPN и настройки не меняются.
Адрес закрытой копии будет показан; он доступен только root.

Сначала обнови сервер, затем соответствующий плагин и синхронизируй выбранные
материалы. В режиме точного ответа введённый текст проходит через Telegram
и сервер; ожидающие ответы и резервные копии могут хранить этот текст.

При ошибке не удаляй журналы и не подменяй их старой копией: так можно потерять
новые ответы. Параллельные ручные изменения программы тоже не перезаписываются.
Утилита оставляет службу остановленной; правила восстановления
описаны в `INSTALL.md`.

## Экран занятия внутри Telegram

В пакете есть необязательный Mini App: чекбоксы, ввод ответа, подсказки и оценки
в одном окне. Первое включение и проверка описаны в `MINIAPP-ru.md`. После
включения отправьте `/app` боту. Выбор материалов по-прежнему задаётся в Obsidian.

## Проверить или остановить

```sh
sudo systemctl status anchor-recall-companion --no-pager
sudo journalctl -u anchor-recall-companion -n 40 --no-pager
sudo systemctl stop anchor-recall-companion
```

Не удаляй конфигурацию и папку состояния ради повторной установки: там
подключения пользователей и ожидающие результаты. Ручная установка,
обновление и восстановление описаны в `INSTALL.md` из пакета.
